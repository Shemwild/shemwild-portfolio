# 🚀 Shemaiah Paramesvaran — Portfolio

Interactive portfolio built with Next.js, TypeScript, Tailwind CSS, GSAP, and Framer Motion, featuring a 3D interactive keyboard, custom resume viewer, blog, and contact form integration.

## ✨ Features

- **Interactive 3D Experience** — Custom 3D keyboard where each keycap represents a skill
- **Interactive Resume Page** — Built-in resume doodle tool & direct PDF download
- **Space Theme** — Dark mode with space aesthetic
- **Contact Form** — Integrated with Formspree (`https://formspree.io/f/xeajvepa`)
- **Responsive & Modern** — Mobile-friendly design with smooth animations

## 🛠️ Tech Stack

- **Framework**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI, Aceternity UI
- **Animations**: GSAP, Motion / Framer Motion
- **Contact**: Formspree

## 🛠️ Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
